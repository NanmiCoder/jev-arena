# README 演示来源

直接在项目网页上选择已有录像，设置 **1×**，点击「播放」后录制前 **20 秒**。未加速、未压缩时间，也未重新调用模型。

- 录像：`0919-124001`，2026-09-19。
- 输入：相同的 10,000 条评论。
- 左侧：`typesafe/jev-1.13`；右侧：`deepseek-flash`。
- 历史配置：两侧并发各 12，每批最多 10 条，与当前网页默认并发设置不同。
- 原始整场完成用时：左侧 203,207 ms；右侧 823,503 ms。GIF 只展示开头，不跳到终局。
- 原速录屏后按墙钟时间采样，导出为 1000 × 413、4 fps 的 20 秒 GIF，无限循环。降低帧率与分辨率只减少文件体积，不改变播放速度。
- 画面中的评论、标签、进度与费用由现有回放界面呈现，未替换为模拟数据。
- GIF 中费用沿用历史记录：Jev 来自供应商返回值，DeepSeek 来自当时项目的本地价格估算；不是当前报价。

这是一次特定数据集、模型版本、并发配置与网络条件下的演示，不能代表所有任务的性能或质量结论。

## 重新录制

原始 `runs/` 不随仓库发布。持有录像时，启动本地项目，在回放栏选择该录像，将倍速设为 **1×**，点击「播放」，录制最初 20 秒即可。回放只读事件文件，不需要 Key，不调用模型。

本次通过 Ego Lite 对真实页面逐帧截图，保存墙钟时间用于检查录制时长。GIF 使用 beautify-github-readme 的 `render_motion_gif.py` 中 `encode_gif` 编码流程：共享色板、无抖动、差分区域、无限循环。没有时间加速滤镜。
