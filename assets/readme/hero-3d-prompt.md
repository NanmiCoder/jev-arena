# 3D Hero 制作说明

工具：内置 image_gen（非 CLI）。用途：README 顶部静态形象图；下方 GIF 承担真实演示。

受众：想用自己的评论复现模型对比的开发者与创作者。
价值：同一批评论输入两侧模型，观察标签、速度与费用，并回放结果。
视觉：深石墨色背景，沿用界面的绿蓝赛道；磨砂玻璃卡片、缎面金属底座、立体象牙白标题。
构图：3:1 横幅，共用输入分流到两侧轨道，保持文字与卡片可辨认。
字体：大号粗体无衬线立体标题；正文保留 Markdown。
形状：圆角评论卡片、低矮轨道、精细倒角。

## Final prompt

Use case: stylized-concept
Asset type: premium static 3D GitHub README hero banner for the actual project "Jev Arena".
Primary request: a beautiful polished 3D hero with a project-native two-lane comment-processing arena, not a generic AI illustration.
Scene: cinematic dark graphite studio background #10151c, restrained mint-green #2ee6a8 and electric-blue #4d8dff lighting matching the application's two comparison lanes.

Bold large clearly readable title "JEV ARENA" integrated across the upper-left/center, with refined ivory solid lettering, slight sculptural extrusion and precise edges. All objects safely inside the frame with generous margins.
Materials: frosted glass comment tiles, satin aluminum track bases, mint/blue translucent acrylic accents. Realistic soft contact shadows, beautiful ambient occlusion, subtle reflections; exceptionally high-end 3D product rendering.
Text verbatim: "JEV ARENA" only. J E V, then A R E N A. No additional text, numbers, fake benchmarks or logos. Title must remain readable at GitHub width and mobile scale.
Constraints: static image; no robots, brains, mascots, generic glowing spheres, excessive neon, fake screenshots, busy circuit patterns or watermark. This is an illustrative title image; the real app GIF will appear below it. Wide composition ideally 1536×512 or an equivalent 3:1 ratio.
